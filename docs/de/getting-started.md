# Erste Schritte

Diese Anleitung hilft Ihnen beim Einstieg in die Förderrecherche App.

## Überblick

Die App ist modular aufgebaut und bietet verschiedene Tabs für unterschiedliche Aufgaben:

1. **Ausschreibungs-Zusammenfassung**: Starten Sie hier, um eine URL zu einer Forschungsausschreibung zu analysieren.  
2. **FIT Suche**: Suchen Sie direkt in der FIT-Datenbank nach neuen Fördermöglichkeiten.  
3. **Unternehmens-Indexierung**: Fügen Sie potenzielle Partner Ihrer Datenbank hinzu.  
4. **Matching & Hybrid-Suche**: Finden Sie die besten Partner für einen Call.  
5. **LinkedIn Integration**: Nutzen Sie Ihr Netzwerk für Kooperationen (derzeit eingeschränkt).  
6. **Datenbank-Ansicht**: Verwalten Sie alle indexierten Unternehmen an einem zentralen Ort.  

## Schnelleinstieg (Quickstart)

1. **Konfiguration**: Stellen Sie sicher, dass Sie einen LLM-Anbieter und den API-Schlüssel in der Seitenleiste konfiguriert haben.  
2. **Analyse**: Geben Sie im ersten Tab eine URL ein (z.B. von der BMBF-Webseite) und klicken Sie auf **Ausschreibung analysieren**.  
3. **Ergebnis**: Sie erhalten eine strukturierte Zusammenfassung und Metadaten (Deadline, Budget, etc.).  
4. **Matching**: Wechseln Sie zum Tab "Matching", um automatisch Unternehmen aus Ihrer Datenbank zu finden, die zu diesem Call passen.
