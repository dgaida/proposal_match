# Fehlerbehebung

Häufige Probleme und deren Lösungen.

## LLM-Fehler

### Verbindung fehlgeschlagen
- **Ursache**: Ungültiger API-Schlüssel oder Netzwerkprobleme.
- **Lösung**: Überprüfen Sie den API-Schlüssel in der Seitenleiste. Stellen Sie sicher, dass Sie eine Internetverbindung haben.

### Modell nicht gefunden
- **Ursache**: Das ausgewählte Modell (z.B. GPT-4) ist nicht für Ihr Konto verfügbar.
- **Lösung**: Lassen Sie das Modellfeld leer (die App nutzt dann Standardwerte) oder geben Sie ein Modell ein, auf das Sie Zugriff haben.

## FIT Suche

### Login fehlgeschlagen
- **Ursache**: Falsche FIT-Zugangsdaten.
- **Lösung**: Überprüfen Sie Benutzername und Passwort. Stellen Sie sicher, dass Ihr FIT-Konto aktiv ist.

### Keine Ergebnisse
- **Ursache**: Die Suchbegriffe sind zu spezifisch.
- **Lösung**: Versuchen Sie es mit allgemeineren Begriffen (z.B. "KI" statt "Transformer-Modelle für maritime Anwendungen").

## Indexierung

### URL kann nicht gecrawlt werden
- **Ursache**: Die Webseite blockiert Scraping oder erfordert JavaScript.
- **Lösung**: Versuchen Sie, Informationen manuell hinzuzufügen, oder verwenden Sie eine andere Quelle.

## LinkedIn Integration

!!! warning
    Die LinkedIn-Integration ist derzeit aufgrund von Anti-Scraping-Maßnahmen eingeschränkt.

- **Problem**: Es werden keine Kontakte gefunden.
- **Lösung**: LinkedIn blockiert automatisierte Anfragen. Verwenden Sie die App stattdessen, um Partner manuell zu identifizieren und kontaktieren Sie diese direkt über die LinkedIn-Webseite.
